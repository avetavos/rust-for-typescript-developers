## Cargo คือ npm + tsc + jest ในเครื่องเดียว

ถ้าเคยใช้ `npm` (หรือ `yarn`/`pnpm`) มาก่อน Cargo จะคุ้นมือทันที เพราะจัดการ dependency, build project, รันโค้ดและรัน test ได้ครบในตัวเดียว

## สร้าง project ใหม่

```bash
# Node / TypeScript
mkdir my-app && cd my-app
npm init -y
npm install typescript --save-dev

# Rust
cargo new my-app   # creates a binary (has fn main)
cargo new my-lib --lib   # creates a library (no fn main)
cd my-app
```

## เพิ่ม dependencies

```bash
# npm
npm install serde_json        # runtime dep
npm install --save-dev vitest # dev dep

# Cargo
cargo add serde_json          # runtime dep
cargo add --dev pretty_assertions  # dev dep
```

`cargo add` อัปเดต `Cargo.toml` อัตโนมัติ เหมือนกับ `npm install` ทุกประการ

## Subcommand หลัก

```bash
cargo build          # compile (debug, fast, unoptimized)
cargo build --release  # compile (optimized, slower build)
cargo run            # compile + execute
cargo run -- --port 8080  # pass args to your binary
cargo check          # type-check only, no binary (very fast)
cargo test           # run all tests
cargo test my_fn     # run tests whose name contains "my_fn"
cargo doc --open     # generate + open HTML docs
cargo clean          # delete target/ directory
```

## Cargo.lock — commit หรือไม่?

```bash
# Binary / application  →  COMMIT Cargo.lock (reproducible builds)
# Library crate         →  DO NOT commit Cargo.lock (let consumers pick versions)
```

นี่สอดคล้องกับ convention ของ npm: application commit `package-lock.json` แต่ library ที่ publish มักไม่ commit

<RsOnly title="edition = 2024 คืออะไร">

Rust ออก **edition** ใหม่ทุก 3 ปี (2015, 2018, 2021, 2024) edition อาจมี syntax change ที่ breaking แต่ compiler สามารถ migrate code ให้อัตโนมัติด้วย `cargo fix --edition` สำหรับ project ใหม่ให้ใช้ `edition = "2024"` — `cargo new` เลือกให้อยู่แล้ว และเป็นตัวที่ปลดล็อก let chain, การ drop temporary ของ `if let` ก่อนเข้า branch `else` และ `unsafe extern` block

สิ่งที่ใกล้เคียงที่สุดฝั่ง TypeScript คือ `target`/`lib` ใน `tsconfig.json` แต่ต่างกันข้อสำคัญ: edition กำหนด **ต่อ crate** ไม่ใช่ต่อทั้งโปรแกรม crate ที่ใช้ 2024 depend crate ที่ใช้ 2015 ได้และกลับกันก็ได้ ecosystem จึงไม่แตก และคุณอัปเกรดตามจังหวะตัวเองได้

</RsOnly>
